# ⭐ StarCatcher

> Аркадная игра на HTML5 Canvas — собирай звезды на время!

## 🎯 О проекте

Мини-игра на чистом JavaScript и Canvas API. Ты управляешь синим квадратом, 
который скользит по экрану с реалистичной физикой (инерция, ускорение, трение). 
Цель — собрать как можно больше золотых звезд за 30 секунд.

Проект создан как часть моего портфолио **PortfolioForge** — 
я собираю его постепенно, шаг за шагом.

## 🎮 Как играть

1. Открой `index.html` в браузере
2. Управляй героем:
   - **Стрелки** или **WASD** — движение
   - **Пробел** — рестарт после окончания игры
3. Собирай золотые звезды ⭐
4. Следи за таймером ⏱️ в правом верхнем углу
5. Когда время выйдет — увидишь свой результат

## 🛠️ Технологии

- HTML5 Canvas (`<canvas>`)
- CSS3 (центрирование, тёмный фон)
- JavaScript (Vanilla, без библиотек)
- `requestAnimationFrame` — плавная анимация 60 FPS

## 🧠 Что внутри (логика)

- **Физика героя**: `vx`, `vy` (скорость), `acceleration` (ускорение), `friction` (трение), `maxSpeed` (максимум)
- **Ограничения (клэмпы)**: герой не выходит за края экрана
- **Коллизия круг-квадрат**: `touchesStar()` через `Math.max/min` — находит ближайшую точку
- **Игровой цикл**: `update()` → `draw()` → `requestAnimationFrame(loop)`
- **Управление**: объект `keys`, `keydown`/`keyup`, `preventDefault()` для стрелок
- **Таймер**: `setInterval` уменьшает `timeLeft` раз в секунду
- **Рестарт**: пробел при `gameOver` вызывает `restart()`
